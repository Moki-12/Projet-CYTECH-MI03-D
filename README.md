## Introduction 📝

FlipTech est un jeu de cartes de prise de risque développé en langage C. Le but est d'accumuler le plus de points possible sans piocher de doublons. Le programme gère les statistiques de la pioche en temps réel pour aider les joueurs dans leurs décisions. Ce projet a pour objectif de mettre en pratique la manipulation des structures, des fichiers et l'affichage graphique en console.

## Pré-requis

* **Make**
